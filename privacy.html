Privacy Policy

Last updated: 20 November 2026

ContentClipper is a desktop tool used only by its operator to upload videos to channels the operator owns. This policy explains how it handles Google user data.

Google user data we access

  • YouTube upload access (youtube.upload): used only to upload videos the operator created to the connected channel.
  • YouTube read-only access (youtube.readonly): used only to read the connected channel's name and handle, to confirm videos go to the intended channel.

How the data is used and stored

  • Sign-in tokens are stored only on the operator's own computer and are used only to make the uploads above.
  • No Google user data is sold, shared with third parties, used for advertising, or used to train AI models.
  • ContentClipper does not read viewers' data, comments, subscriptions, or any other account data.

ContentClipper's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

You can remove ContentClipper's access at any time at myaccount.google.com/permissions. Deleting the tool's saved tokens on the computer also ends its access.
