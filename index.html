ContentClipper

ContentClipper is a private desktop tool that turns livestream moments into short vertical videos and uploads them to the operator's own social media channels, such as YouTube Shorts.

What it does

  • Watches livestreams the operator is permitted to clip and cuts short highlight videos.
  • Uploads finished videos to YouTube channels that the operator owns and has connected.
  • Checks which YouTube channel was connected, so videos only go to the intended channel.

ContentClipper runs on the operator's own computer. It is not offered to the public and has no user accounts.
